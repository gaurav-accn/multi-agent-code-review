simplify at sanitizeInput function (lines 32-38) (low impact)

Use a lookup table with Object.entries to reduce repetitive replace calls.

Before
export function sanitizeInput(input: string): string {
  return input
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#039;');
}
After
export function sanitizeInput(input: string): string {
  const HTML_ENTITIES: Record<string, string> = {
    '<': '&lt;',
    '>': '&gt;',
    '"': '&quot;',
    "'": '&#039;'
  };
  return input.replace(/[<>"']/g, (char) => HTML_ENTITIES[char]);
}

Benefits: Single regex pass instead of four; easier to add new entities; clearer mapping of character to entity.

function validateUserInput(input: CreateUserInput): void {
  if (!input.email || !input.name) {
    throw new Error('Email and name are required');

  }

export async function createUser(input: CreateUserInput): Promise<User> {
  validateUserInput(input);

  const user: User = {
    id: generateId(),
    email: input.email.toLowerCase(),
    name: sanitizeInput(input.name),
    createdAt: new Date()

  await saveUser(user);
  return user;
